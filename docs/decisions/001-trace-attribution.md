# ADR 001 · 分离测量、归因和假设

- 禁用 ORT Graph 优化以便校验原始模型与执行节点的对应关系。这样可给适配实验提供稳定诊断条件。若后续评估部署性能，应再添加一组开启生产优化的成对运行。
- 使用同一输入的两种 ORT Session，分别写入真实 Trace 和测量无插桩延迟。热点评分采用每个 Trace 内所有 operation 持续时间之和。时间窗口、并发和采集开销都会影响这两个指标的关系。
- 归因以唯一节点名和算子类型相符为证据。超过映射证据范围时保留 Unknown，同一个映射覆盖多个模块时保留 Shared。两个分类的耗时仍计入原始范围。
- 用显式规则生成假设。将实测、导入、Fixture 和待测试的假设分别建立字段，方便客户端展示证据的来源。
- 用版本化 adapter 承接外部格式。Optrace 路径基于官方所指向的 Chrome Trace 交换格式，合成 Fixture 用于验证该格式子集和异常处理。原生 QNN 数据需用实际版本样本补足。
